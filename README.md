# 🎯 Gift Catcher

Telegram-бот («снайпер») для отслеживания новых NFT-подарков. Если последний номер подарка — #1000,
то при появлении #1001 (в том числе после апгрейда обычного подарка) бот присылает алерт со ссылкой.

## Возможности
- Каталог подарков по алфавиту, формат «Название · код», поиск текстом
- Массовый выбор («Выбрать все 1.1.1»)
- Фильтр по модели для одного выбранного подарка
- Фоновая проверка каждые 25 секунд
- SQLite, aiogram 3, asyncio

## Быстрый старт
    git clone https://github.com/DevMack777/Gift-catcher.git
    cd Gift-catcher
    python -m venv .venv
    pip install -r requirements.txt
    cp .env.example .env
    python main.py

В `.env` впишите токен от @BotFather.

## Структура
- `main.py` — точка входа
- `config.py` — настройки, список коллекций
- `db.py` — работа с SQLite
- `nft_client.py` — сетевые запросы, парсинг страницы подарка
- `sniper.py` — фоновая задача и отправка алертов
- `bot/handlers.py`, `bot/keyboards.py` — интерфейс бота

## Настройка
- Список подарков: `COLLECTIONS` в `config.py` (код = часть ссылки `t.me/nft/<код>-<номер>`).
- Интервал проверки: `CHECK_INTERVAL` в `config.py`.

## Важно
- Официального API Telegram для списка NFT-подарков нет, бот читает публичные страницы `t.me/nft/...`.
  Если Telegram изменит вёрстку, поправьте `NftClient._parse` в `nft_client.py`.
- Никогда не коммитьте `.env` и токен бота.
- Бот только присылает уведомления и ничего не покупает.
